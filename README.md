# PocketAI

PocketAI is a simple and light weight python program you can use to make
your local AI models accessible via telegram.

# Commands and help

/help - shows a little help message
/models - shows every installed local model (ollama)
/model <Model name> - changes the used model
/stats - shows max RAM, current used RAM in gb, current used RAM in % and current CPU usage
/quest <your prompt> - Send a prompt to the bot like you would normally.
